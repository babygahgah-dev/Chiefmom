# 病房普通話 Ward Putonghua

Learn 200 medical terms and 40 key patient phrases in Putonghua from Cantonese, with built-in audio, sound-alike drills, bedside scenarios, streaks and spaced review.

## Run it

- **Online:** hosted with GitHub Pages at https://babygahgah-dev.github.io/Chiefmom/
- **Locally:** open `index.html` in any modern browser. No install or build step is needed.

Progress (streaks, review schedule) is saved in your browser's local storage, so it stays on the device and browser you use.
